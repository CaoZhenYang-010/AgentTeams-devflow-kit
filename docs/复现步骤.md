# 复现步骤

> 目标：评审人员在已有 AgentTeams 环境的机器上，一键跑通"需求→发布"完整闭环。

## 前置条件

- Docker + AgentTeams 已安装运行（`agentteams-controller` / `agentteams-manager` 容器 Running）
- Element Web 可访问（http://127.0.0.1:18088），有 admin 账号
- AgentTeams 工作区：`C:\Users\<用户名>\agentteams-manager`（Windows）或 `~/agentteams-manager`

## 第一步：创建 8 个 Agent + 2 个 Team

```bash
cd AgentTeams-devflow-kit
bash scripts/apply.sh
```

验证：
```bash
docker exec agentteams-controller agt get workers   # 8 个 Running
docker exec agentteams-controller agt get teams     # architecture-team + quality-team
```

## 第二步：分发 11 个 Skill

```bash
bash scripts/install-skills.sh
```

然后在 Element Web 的 manager 房间让 Manager 安装并分发 Skill，
并确认各 Worker 的 `spec.skills` 已更新。

## 第三步：准备模板工程

把 `stack-template`（backend + frontend）复制到共享区：

```bash
# 上传到 MinIO shared/
docker exec agentteams-controller mc cp -r \
  /root/agentteams-fs/agents/manager/<stack-template> \
  agentteams/agentteams-storage/shared/projects/
```

## 第四步：发起流水线

```bash
bash scripts/run.sh "开发一个运费计费引擎：输入订单列表（里程km、重量kg、服务等级normal/express），规则：基础费5元含首3km和首5kg；超过3km每km加2元；超过5kg每kg加1元；express加收30%；单笔订单总额超100元打9折；总价不足5元按5元计。输出每单明细与汇总"
```

devflow-runner 读取 `workflow.yaml` 驱动流水线，Element Web 全程可见各 Agent 派发与产物。

## 第五步：验证结果

| 检查点 | 期望 |
|--------|------|
| Element Web 各 Agent 房间有任务派发记录 | ✅ |
| `shared/runs/{run-id}/` 有 task.md / design.md / 各报告 | ✅ |
| `test_report.txt` 含 BUILD SUCCESS + 覆盖率 | ✅ |
| `defect_report.md`（如有失败回流）定位到文件/行 | ✅ |
| 发布节点 git commit `[ci pass]` | ✅ |
| `trace.log` 完整记录每节点 enter/exit/rollback | ✅ |

## 常见问题

- **Skill 没分发成功**：确认 `spec.skills` 已更新（`agt get workers <name> -o json \| jq '.skills'`）
- **tester 读不到代码**：确认工程在 `shared/runs/{run-id}/work/` 且 Worker 有读写权限
- **回流不生效**：检查失败证据文件存在且未含通过标记

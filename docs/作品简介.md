# DevFlow Kit 全自动软件研发流水线

**问题与场景**：企业 AI 编程落地面临流程断裂、协同断裂、黑盒断裂——AI 只是高级补全，多 Agent 难可靠协同，产出不可审计。

**核心解决方案**：基于 AgentTeams 构建 8 个职能 Agent 研发团队，`run-pipeline.py` 一键驱动 13 节点流水线（设计→编码→测试→对抗→E2E→门禁→发布），验证由真实工具保证（测试、覆盖率、对抗测试、影响面）。

**创新点与差异化优势**：① 全自动流水线——发需求即自动跑完研发闭环；② 验证机制化——覆盖率、对抗、门禁程序化判定而非模型自评；③ 门禁回流——不通过自动定位修复、重跑验证。

**开放/复用价值**：全量开源（Apache-2.0），Skill/Agent/流水线开放格式，可跨团队、工具、行业复用。

**当前进展**：8 Worker + 2 Team 落地，自定义 Worker 镜像构建完成；Demo 全栈自动化流水线开发案例已**全链路跑通**——13 节点自动完成（含测试、覆盖率、对抗、E2E、门禁、发布、通知 Manager），验证"发需求即跑完"能力。
